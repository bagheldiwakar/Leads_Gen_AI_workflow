# X-Security 10-Minute Demo Script

## 1. Set context — 1 minute
“Before I show anything, I want to confirm the endpoint-security problem you are trying to solve and what a useful outcome would look like.”

## 2. Show the problem-to-platform flow — 2 minutes
Explain how an endpoint is enrolled, how policies are applied and how the operator sees coverage.

## 3. Show prevention and visibility — 2 minutes
Demonstrate the proposed workflow for policy status, device posture and prevention events. Do not simulate claims as live product results.

## 4. Show detection and response — 2 minutes
Walk through the intended alert-to-investigation-to-response workflow, clearly separating available prototype functions from roadmap items.

## 5. Show reporting — 2 minutes
Show the type of operational and executive reporting X-Security is designed to produce: coverage, priority events, response status and trends.

## 6. Ask for the pilot — 1 minute
“Would it be useful to test this with a limited endpoint group against the success measures we discussed?”

## Demo discipline
Use the buyer's language and problem. Keep the demo focused on one use case. Never claim a capability that is not currently demonstrated.
