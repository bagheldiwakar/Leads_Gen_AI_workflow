# X-Security Outreach Learning Memory

This file is the knowledge base for the AI outreach assistant.

## Purpose
Use real outreach outcomes to identify which message angle, channel, target type and follow-up step lead to replies, discovery calls, pilots and wins.

## Rules
- Learn only from recorded outcomes; never invent performance data.
- Keep a human reviewer responsible for every message and recommendation.
- Prefer qualified meetings and pilots over raw message volume.
- Treat a response as useful only when the dashboard records an outcome.

## Message angles
- Endpoint visibility and centralized policy
- Faster detection and response
- Multi-client managed-security operations
- Client reporting and proof of service value
- Endpoint-security pilot / assessment offer

## Outcome labels
- No response
- Positive reply
- Discovery call booked
- Qualified opportunity
- Pilot proposed
- Pilot active
- Closed won
- Closed lost

## AI recommendation prompt
Given the learning log and a target brief:
1. Compare the target type and buyer role with prior outcomes.
2. Recommend the best channel and message angle.
3. State the evidence used.
4. If there is insufficient data, say so and use the baseline outreach sequence.
5. Draft a short message for human review; do not send it automatically.
